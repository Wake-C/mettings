# 更新日志 / Changelog

## v0.2.0 · 2026-11-17

首次开源发布，采用 MIT 许可证，提供中文和英文说明。

1. **先录音，后转写**：会议录音、音频导入和桌边守候，按需选择本地模型，保留每次转写的独立版本。
2. **整理说话人的声音**：标注说话人，复用本地声音库，手动修正匹配结果。
3. **固定发布签名**：Apple Silicon DMG 使用持久自签名证书并附带 SHA-256 校验文件；未经 Apple 公证，仍可能需要首次打开确认及隐私授权。

First open-source release under MIT, with Chinese and English introductions.

1. **Record first, transcribe later**: meeting recording, audio import and opt-in Desk mode, local model choices and independent transcript versions.
2. **Review speakers**: label speakers, reuse a local voice library and correct suggested matches.
3. **Persistent release signing**: an Apple Silicon DMG signed with a persistent self-signed certificate, plus a SHA-256 checksum. Not Apple-notarized; first-launch approval and privacy permissions may still be required.
